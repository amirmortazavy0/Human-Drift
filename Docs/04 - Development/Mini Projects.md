## MP-001 — Manual Train Session Logger (CLI)

**Status:** Idea
**Journey:** Journey-001 Train Performance
**Goal:** A Python command-line script that lets me manually log departure and arrival times and saves them to a JSON file.

**What I'll learn:**
- Python file I/O
- JSON read/write
- Datetime handling
- Simple CLI input

**Output:** A working session log I can actually use during commutes while the automated version is being designed.

**This project matters because:** The manual version makes the automated version real. You understand what you're building before you automate it.

## MP-002 — Train Simulator (future)

**Status:** Idea — do not start until MP-001 is complete
**Journey:** Journey-001 Train Performance
**Goal:** Simulate a month of train commutes programmatically using fake GPS coordinates and timestamps, to test the Context Detection and Event Model without needing to ride an actual train every day.

**This project matters because:** You cannot test a 30-day Program by waiting 30 days. A simulator lets you run the entire program lifecycle in minutes.
