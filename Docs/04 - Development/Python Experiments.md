## EXP-001 — Manual train session logger

**Date:** —
**Goal:** Can I log departure and arrival timestamps manually from the command line and save them to a JSON file?
**Journey it relates to:** Journey-001 Train Performance
**Status:** Not started

This is the simplest possible version of the train program — no context detection, no automation. Just: run script → type "departed" → type "arrived" → script saves a record.

Building this first makes the automation goal concrete. You understand exactly what you're trying to automate before you automate it.
