# Inbox

Fast capture only. One line per idea.

Format:
```
[idea or URL] — [why it might matter, one sentence]
```

Process into the right folder within 24 hours.
If an idea doesn't survive 24 hours, it wasn't worth capturing.

Where things go after the Inbox:
- Research finding → `01 - Research/Evidence/`
- Product idea → `02 - Product/User Journeys/` (as a new journey)
- Architecture insight → `03 - Architecture/`
- Development task → `04 - Development/`
- Doesn't fit → `01 - Research/Synthesis/Dead Ends.md`
